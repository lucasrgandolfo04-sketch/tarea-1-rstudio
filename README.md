
# Miniproyecto 1 - Análisis de Flores

**Materia:** Métodos Informáticos

**Autor:** Lucas Gandolfo

## Descripción del proyecto

Este proyecto consiste en analizar el conjunto de datos
iris utilizando RStudio y R Markdown.

El objetivo es conocer las características de tres
especies de flores y comparar las medidas de sus pétalos.

## Objetivos

- Explorar el conjunto de datos iris.
- Calcular estadísticas descriptivas.
- Obtener el promedio del largo de los pétalos.
- Comparar las tres especies de flores.
- Representar los resultados mediante gráficos.

## Herramientas utilizadas

- R
- RStudio
- R Markdown
- Git
- GitHub

## Archivos del proyecto

- Reporte_Flores.Rmd: informe con el código y análisis.
- Reporte_Flores.html: reporte generado mediante Knit.
- README.md: descripción del proyecto.

## Cómo ejecutar el informe

1. Abrir el proyecto en RStudio.
2. Abrir el archivo Reporte_Flores.Rmd.
3. Presionar el botón Knit.
4. Visualizar el reporte HTML generado.

## Conclusión

El análisis permitió observar diferencias en el largo
de los pétalos de las especies setosa, versicolor
y virginica.

Además, aprendí a generar informes reproducibles
utilizando R Markdown y a guardar los cambios
del proyecto mediante GitHub.
